Astăzi învățăm împreună bazele sintaxei Python. Fără ele nu putem scrie programe reale. Vorbim despre comentarii, variabile, nume corecte și regulile simple care fac Python atât de ușor.

Comentariile sunt bucăți de text care trăiesc în cod, dar Python le ignoră complet. Le folosim ca să explicăm ce face codul sau de ce l-am scris așa. Ca să scrii un comentariu, pui un hashtag (#) înainte: # Acesta este un comentariu în Python Poți face și comentarii pe aceeași linie: greeting = "Hello" # acest text este ignorat de Python Comentariile trebuie să fie scurte și la obiect — cam sub 72 de caractere. Dacă e prea lung, îl împarți în două linii: # Acesta este un comentariu lung # împărțit pe două linii.

O variabilă este un nume pe care îl dai unei valori. Este ca o cutie în care pui ceva. Sintaxa este foarte simplă: ```python nume_variabila = valoare Exemple: first_num = 1 numbers = [1, 2, 3, 4, 5] Poți vedea ce ai în variabilă doar scriind numele ei: numbers Python permite și caractere Unicode: π = 3.14 Dar în practică, folosește doar litere, cifre și underscore — este cel mai clar și cel mai profesionist.”

Variabilele nu pot începe cu cifre. Uite un exemplu greșit: 1rst_num = 1 Python o să dea: SyntaxError În schimb: first_num = 1 funcționează perfect. Regula generală: • folosește litere, cifre și _ • numele începe întotdeauna cu o literă • scrie-le în snake_case: adică litere mici + underscore Exemplu bun: user_age = 25

Sintaxa Python este clară și gândită special pentru începători. Dacă poți citi engleza simplă, poți citi și Python. Tot ce scriem în Python trebuie să respecte câteva reguli: • comentariile încep cu # • variabilele au nume clare • numele nu pot începe cu cifre • codul trebuie să fie ușor de înțeles Dacă scrii cod clar, te vei felicita peste 6 luni când te întorci la el

Vezi scriptul lecției

Introducere

Acum învățăm două lucruri foarte importante în Python: keywords – cuvintele speciale ale limbajului – și tipurile de date, adică materialele din care este construit orice program.

Keywords în Python

În Python există câteva cuvinte rezervate. Ele fac parte din limbaj și au un rol special.

Nu le poți folosi ca nume de variabile, deoarece Python îți va da eroare.

Ca să vezi lista completă, în terminal scrii:

help("keywords")

Lista conține cuvinte precum:

if, else, for, while, def, class, True, False,
None, import, return, break, continue

Fiecare dintre ele are un rol clar în limbaj:

  • if – este folosit pentru condiții;
  • for – este folosit pentru bucle;
  • def – definește o funcție;
  • class – creează clase.

Python mai are și soft keywords, care funcționează ca keywords numai în anumite situații. De exemplu: match și case.

Le poți vedea folosind:

import keyword print(keyword.kwlist) print(keyword.softkwlist)

Ce sunt tipurile de date?

Tipurile de date sunt formele în care Python stochează informațiile. Gândește-te la ele ca la diferite feluri de cutii.

1. Numere

Numerele sunt folosite atunci când vrem să numărăm sau să calculăm ceva.

a = 10 # int b = 3.14  # float c = 3 + 2j   # complex

Exercițiu: salvează vârsta și câți bani ai, apoi afișează-le.

# Program cu numere

varsta = 10
bani = 15.5

print("Numele meu este Carlita")
print("Am", varsta, "ani")
print("Am", bani, "lei")

Ce înveți:

  • numere;
  • variabile;
  • afișarea informațiilor.

2. Boolean

Boolean înseamnă doar două posibilități: adevărat sau fals, adică True sau False.

Exercițiu: spune dacă plouă sau nu. 

# Program cu Boolean

ploua = True

print("Numele meu este Carlita")
print("Plouă afară?")
print(ploua)

Ce înveți:

  • True și False;
  • cum păstrezi un răspuns de tip da sau nu;
  • afișarea unei valori Boolean.

3. String

Un string este orice text: un nume, un cuvânt sau o propoziție. Textul este scris între ghilimele.

Exercițiu: salvează numele și afișează un salut. 

# Program cu text

nume = "Carlita"

print("Salut!")
print("Numele meu este", nume)

Ce înveți:

  • cum păstrezi un text;
  • folosirea ghilimelelor;
  • afișarea textului.

4. Listă

O listă este ca o cutie în care poți pune mai multe lucruri.

Exercițiu: creează o listă cu jucării. 

# Program cu listă

jucarii = ["minge", "păpușă", "mașină"]

print("Numele meu este Carlita")
print("Jucăriile mele sunt:")
print(jucarii)

Ce înveți:

  • liste;
  • mai multe valori într-o singură variabilă;
  • afișarea unei liste.

5. Tuple

Un tuple este asemănător unei liste, dar valorile sale nu pot fi modificate după ce a fost creat.

Exercițiu: salvează două culori preferate care nu se modifică. 

# Program cu tuple

culori = ("roșu", "albastru")

print("Numele meu este Carlita")
print("Culorile mele preferate sunt:")
print(culori)

Ce înveți:

  • date fixe;
  • diferența dintre o listă și un tuple.

6. Dicționar

Un dicționar păstrează informațiile sub forma cheie – valoare.

De exemplu, cheia este nume, iar valoarea este Carlita.

Exercițiu: creează un dicționar cu informații despre tine. 

# Program cu dicționar

persoana = {
    "nume": "Carlita",
    "varsta": 10
}

print("Informații despre mine:")
print(persoana)

Ce înveți:

  • cheie și valoare;
  • organizarea informațiilor;
  • crearea unui dicționar.

7. Set

Un set este o colecție care nu păstrează valorile duplicate.

Exercițiu: creează un set cu numere repetate. 

# Program cu set

numere = {1, 2, 3, 3, 3}

print("Numele meu este Carlita")
print("Numerele fără dubluri sunt:")
print(numere)

Chiar dacă numărul 3 este scris de mai multe ori, Python îl păstrează o singură dată.

Ce înveți:

  • eliminarea valorilor duplicate;
  • crearea și folosirea seturilor.

Python are și tipul de date bytes, dar pentru început nu trebuie să intrăm în detalii despre el.

Regulă importantă pentru variabile

  • Nu folosi spații în numele variabilelor.
  • Folosește caracterul underscore: _.

Exemplu corect:

numele_meu = "Carlita"

Exemplu greșit:

numele meu = "Carlita"

Cum lucrezi cu tipurile de date?

Tipurile de date pot fi modificate sau verificate folosind trei lucruri:

  • Operatori: +, -, /, ==, >;
  • Funcții built-in: len() verifică lungimea, iar type() verifică tipul de date;
  • Metode: de exemplu, .append() adaugă un element într-o listă.

Exemplu:

numbers = [1, 2, 3]

numbers.append(4)

print(numbers)
print(len(numbers))
print(type(numbers))

Tipurile de date: Numerele si Boolean

Deci am văzut rapid tipurile de date. Acum facem zoom pe cele mai importante două: • Numerele (ca să calculezi) • Boolean (ca să iei decizii)

Durată: 03:14

Vezi scriptul lecției

Introducere

În lecția trecută am văzut pe scurt tipurile de date din Python. Acum vom face zoom pe două dintre cele mai importante:

  • Numerele – pentru calcule.
  • Boolean – pentru a lua decizii.

Vom învăța totul folosind exemple simple, pe care le poate înțelege oricine.

1. Tipurile de numere în Python

int – numere întregi

Tipul int reprezintă numere întregi, fără zecimale. 

varsta = 20
pasi = 8432
temperatura = -5

Se folosesc pentru:

  • vârstă;
  • număr de obiecte;
  • scoruri;
  • pași;
  • cantități.

float – numere cu zecimale

Tipul float reprezintă numerele cu zecimale. 

pret = 19.99
inaltime = 1.72
timp = 2.5

Se folosesc pentru:

  • prețuri;
  • greutate;
  • timp;
  • măsurători.

Important

Uneori vei observa că rezultatele cu zecimale nu sunt perfecte. De exemplu: 

print(0.1 + 0.2)

Rezultatul nu este exact 0.3. Acest lucru este normal și apare din modul în care calculatorul stochează numerele cu zecimale.

complex – numere complexe

Python știe să lucreze și cu numere complexe. 

z = 2 + 3j

Acestea au două părți:

  • partea reală: 2;
  • partea imaginară: 3j.

Sunt folosite mai ales în:

  • matematică;
  • fizică;
  • inginerie.

Pentru început nu trebuie să le folosești, dar este bine să știi că există.

2. Operații matematice

Acum vine partea interesantă. Python poate face toate operațiile matematice de bază. 

x = 10
y = 3

print(x + y)   # 13
print(x - y)   # 7
print(x * y)   # 30
print(x / y)   # 3.333...

Operatorul / face împărțirea normală și poate întoarce un rezultat cu zecimale.

Împărțire fără zecimale

print(x // y)   # 3

Operatorul // păstrează doar partea întreagă a rezultatului.

Restul împărțirii

print(x % y)   # 1

Operatorul % întoarce restul împărțirii.

Este foarte util pentru:

  • verificarea numerelor pare și impare;
  • jocuri;
  • rotații;
  • diverse calcule.

Ridicarea la putere

print(x ** y)   # 1000

Operatorul ** înseamnă ridicare la putere.

3. Conversii între tipuri de date

În viața reală, foarte multe date vin sub formă de text. De exemplu, atunci când utilizatorul completează un formular. 

age_text = "20"
age = int(age_text)

price = "15.50"
money = float(price)

Funcția int() transformă un text într-un număr întreg, iar funcția float() îl transformă într-un număr cu zecimale.

Dacă nu faci această conversie, Python va considera că valoarea este text și va genera erori atunci când încerci să faci calcule.

4. Boolean (True / False)

Tipul de date Boolean poate avea doar două valori:

  • True – înseamnă adevărat.
  • False – înseamnă fals.

Acest tip de date este folosit atunci când răspunsul poate fi doar Da sau Nu. 

ploua = True
am_baterie = False

Variabila ploua spune că afară plouă, iar am_baterie spune că dispozitivul nu mai are baterie.

5. Boolean apare din comparații

De cele mai multe ori, valorile Boolean apar atunci când comparăm două valori. 

age = 17

print(age >= 18)

Python verifică dacă valoarea lui age este mai mare sau egală cu 18.

În acest caz, rezultatul va fi False, deoarece 17 este mai mic decât 18.

Acesta este fundamentul instrucțiunii if, pe care o vom învăța în lecțiile următoare.

6. Operatorii de comparație

Python folosește mai mulți operatori pentru a compara valori.

  • == – egal cu;
  • != – diferit de;
  • > – mai mare decât;
  • < – mai mic decât;
  • >= – mai mare sau egal;
  • <= – mai mic sau egal.

Toți acești operatori întorc întotdeauna una dintre cele două valori: True sau False.

7. Exemplu practic

Să verificăm dacă o persoană este adult. 

age = 16

is_adult = age >= 18

print("Este adult?")
print(is_adult)

Variabila is_adult va conține rezultatul comparației.

Deoarece vârsta este 16 ani, programul va afișa False.

Mini proiect – Avem bani suficienți?

Hai să realizăm un program simplu care verifică dacă avem suficienți bani pentru a cumpăra un produs. 

bani = 25.0
pret = 19.99

pot_cumpara = bani >= pret

print("Am bani suficienți?")
print(pot_cumpara)

Programul compară suma pe care o ai cu prețul produsului.

Dacă ai suficienți bani, rezultatul va fi True. În caz contrar, va fi False.

Observă că programul nu doar calculează, ci ia și o decizie pe baza comparației dintre cele două valori.

Durată: 03:14

Vezi scriptul lecției

Introducere

Astăzi vom învăța despre Strings, adică modul în care Python lucrează cu textul.

Dacă știi să lucrezi cu text, deja poți crea programe reale: mesaje, meniuri, afișări și multe altele.

1. Ce este un String?

Un String este o bucată de text. Poate fi un singur cuvânt, o propoziție sau chiar un paragraf întreg.

În Python, un string poate fi scris folosind:

  • ghilimele simple ' ';
  • ghilimele duble " ";
  • ghilimele triple ''' ''' sau """ """.

Exemple:

# String

# Ghilimele simple
print('Hello There')

# Ghilimele duble
print("Welcome to Python!")

# Ghilimele triple
print("""Thanks for joining us!""")

Python acceptă toate aceste variante, iar tu o poți folosi pe cea care face codul mai ușor de citit.

2. Escape Characters

Uneori ai nevoie să scrii caractere speciale într-un string. Pentru asta folosim escape characters, adică caracterul \ urmat de o literă sau un simbol.

De exemplu, dacă vrei să scrii un apostrof într-un text delimitat de ghilimele simple: 

print('can\'t')

Sau poți folosi ghilimele duble și nu mai ai nevoie de caracterul escape: 

print("can't")

Cele mai folosite escape characters sunt:

  • \' – apostrof;
  • \" – ghilimele duble;
  • \n – linie nouă;
  • \t – tab;
  • \\ – backslash;
  • \r – carriage return;
  • \b – backspace;
  • \f – form feed.

Exemplu:

print("Salut\nBine ai venit!")

print("Nume:\tCarlita")

3. Concatenarea Stringurilor

Concatenarea înseamnă unirea mai multor texte într-un singur text.

Cel mai simplu mod este folosind operatorul +. 

print("Hello" + "World")

print("Hello" + " " + "World")

print("Happy" + " " + "Pythoning!")

Observă că spațiile trebuie adăugate manual atunci când este nevoie.

Metoda join()

Dacă ai mai multe bucăți de text, metoda join() este mai eficientă și mai ușor de citit. 

print(" ".join(["Happy", "Pythoning!"]))

Rezultatul va fi: 

Happy Pythoning!

Metoda join() este recomandată atunci când unești mai multe stringuri într-un singur text.

4. Lungimea unui String - len()

Dacă vrei să afli câte caractere are un text, folosești funcția len(). 

text = "Happy Pythoning!"

print(len(text))

Funcția len() numără toate caracterele din string, inclusiv spațiile.

5. Metode utile pentru Stringuri

Stringurile au foarte multe metode deja construite în Python. Acestea te ajută să modifici sau să afișezi textul în diferite moduri.

upper()

Transformă toate literele în majuscule. 

print("hello".upper())

Rezultat:

HELLO

lower()

Transformă toate literele în litere mici. 

print("HELLO".lower())

Rezultat:

hello

6. Formatarea textului

De multe ori vrem să introducem valori într-un text. Python oferă mai multe metode pentru acest lucru.

Metoda format()

name = "Carlita"
age = 35

print("My name is {0} and I'm {1}".format(name, age))

Valorile din variabile sunt introduse automat în pozițiile indicate de acolade.

f-strings

În prezent, cea mai simplă și cea mai folosită metodă este f-string. 

name = "Carlita"
age = 35

print(f"My name is {name} and I'm {age}")

Litera f din fața șirului permite folosirea directă a variabilelor între acolade.

În proiectele moderne Python, f-strings sunt metoda recomandată.

7. Indexarea Stringurilor

Fiecare caracter dintr-un string are o poziție numită index.

Indexarea începe întotdeauna de la 0. 

welcome = "Welcome to Python!"

print(welcome[0])      # W
print(welcome[11])     # P
print(welcome[-1])     # !

Poți folosi și indici negativi.

  • -1 reprezintă ultimul caracter;
  • -2 reprezintă penultimul caracter;
  • și așa mai departe.

Citirea inversă

print(welcome[::-1])

Folosind step = -1, Python afișează textul în ordine inversă.

8. Slicing

Slicing înseamnă extragerea unei bucăți dintr-un string. 

welcome = "Welcome to Python!"

print(welcome[0:7])      # Welcome
print(welcome[11:17])    # Python

Structura generală este: 

string[start:end:step]

Un alt exemplu:

welcome = "Welcome to Python!"

print(welcome[0:7:2])

Unde:

  • start – poziția de unde începe;
  • end – poziția unde se oprește (fără a o include);
  • step – din câte în câte caractere merge.

Rezumat

În această lecție ai învățat:

  • ce este un String;
  • cum se folosesc ghilimelele simple, duble și triple;
  • ce sunt escape characters;
  • cum unești texte folosind + și join();
  • cum afli lungimea unui text folosind len();
  • cum folosești metodele upper() și lower();
  • cum formatezi textul folosind format() și f-strings;
  • cum funcționează indexarea;
  • cum extragi bucăți de text folosind slicing.

Încheiere

Acum știi cele mai importante lucruri despre stringuri în Python.

Ai învățat cum să creezi texte, cum să le modifici, cum să le formatezi și cum să extragi exact informația de care ai nevoie.

Ce sunt Bytes și Bytearray

Durată: 03:07

Vezi scriptul lecției

Introducere

Astăzi vom vorbi despre două tipuri de date pe care mulți începători le evită: bytes și bytearray.

Acestea sunt foarte importante atunci când lucrezi cu fișiere, rețele, imagini sau alte date binare.

Chiar dacă nu le vei folosi imediat, este bine să înțelegi ce sunt și când sunt utile.

1. Ce sunt Bytes?

Un obiect bytes reprezintă o secvență de valori brute, fiecare având o valoare între 0 și 255.

Gândește-te la el ca la un șir de numere mici care reprezintă informații în format binar.

Diferența principală dintre String și Bytes este:

  • String conține text Unicode.
  • Bytes conține text encodat sau date binare.

Exemplu:

print("=== 1. Ce sunt bytes? ===")

text = "Hello"
data = b"Hello"

print("String:", text)
print("Bytes:", data)

print("Tip string:", type(text))
print("Tip bytes:", type(data))

Observă că litera b din fața textului spune lui Python că este un obiect de tip bytes.

2. Cum creezi un obiect Bytes?

Există mai multe moduri prin care poți crea un obiect bytes.

Metoda 1 - Literal

data1 = b"Hello"

print(data1)

Este cea mai simplă metodă și funcționează pentru textul ASCII.

Metoda 2 - Dintr-o listă de numere

data2 = bytes([72, 101, 108, 108, 111])

print(data2)

Fiecare număr reprezintă codul unui caracter.

Metoda 3 - Prin encodare

data3 = "café".encode("utf-8")

print(data3)

Metoda encode() transformă un String într-un obiect de tip bytes.

UTF-8 este una dintre cele mai folosite metode de codificare a textului.

3. Cum transformi Bytes înapoi în text?

Dacă ai un obiect bytes și vrei să îl transformi din nou într-un String, folosești metoda decode(). 

data = b"caf\xc3\xa9"

text_decoded = data.decode("utf-8")

print("Bytes:", data)
print("Text decodat:", text_decoded)

Metoda decode() citește informația binară și o transformă într-un text pe care îl putem afișa și folosi în programele noastre.

4. Indexarea și Slicing pentru Bytes

Obiectele bytes se comportă asemănător cu stringurile. Putem accesa fiecare element folosind indexarea. 

data = b"Hello"

print(data[0])
print(data[1])
print(data[-1])

Există însă o diferență importantă.

În cazul stringurilor, Python întoarce un caracter. În cazul obiectelor bytes, Python întoarce valoarea numerică a acelui byte.

De exemplu:

print(data[0])

Rezultatul va fi 72, deoarece acesta este codul ASCII pentru litera H.

Slicing

La fel ca în cazul stringurilor, putem extrage doar o parte din obiectul bytes. 

data = b"Hello"

print(data[1:4])

Rezultatul este un nou obiect de tip bytes, nu un String.

5. Bytearray

Obiectele bytes sunt immutable, ceea ce înseamnă că nu pot fi modificate după ce au fost create.

Dacă ai nevoie de o versiune modificabilă, Python oferă tipul de date bytearray. 

buffer = bytearray(b"ABC")

print("Înainte:", buffer)

buffer[0] = 97

print("După modificare:", buffer)

În acest exemplu, primul caracter este modificat direct în memorie.

Valoarea 97 reprezintă codul ASCII pentru litera a.

Transformarea unui Bytearray în Bytes

buffer = bytearray(b"ABC")

print(bytes(buffer))

Funcția bytes() transformă un obiect bytearray într-un obiect bytes.

6. Conversii Hex

Obiectele bytes pot fi transformate într-un șir de caractere hexazecimale folosind metoda hex(). 

hex_value = b"Hello".hex()

print(hex_value)

Rezultatul va fi: 

48656c6c6f

Putem face și operația inversă folosind metoda fromhex(). 

back_to_bytes = bytes.fromhex("48656c6c6f")

print(back_to_bytes)

Aceste metode sunt foarte utile atunci când lucrăm cu fișiere binare, protocoale de rețea sau aplicații de securitate.

Rezumat

În această lecție ai învățat:

  • ce sunt obiectele bytes;
  • diferența dintre String și bytes;
  • cum creezi obiecte bytes;
  • cum folosești metodele encode() și decode();
  • cum funcționează indexarea și slicing pentru bytes;
  • ce este bytearray și cum poate fi modificat;
  • cum transformi datele folosind hex() și fromhex().

Încheiere

Acum știi ce sunt bytes și bytearray, cum le creezi, cum le modifici și cum le convertești.

Chiar dacă nu le vei folosi în fiecare program, ele sunt foarte importante atunci când lucrezi cu fișiere, comunicații în rețea sau date binare.

Dicționare și Seturi in Pythonn

Durată: 03:32

Vezi scriptul lecției

Introducere

Astăzi vom învăța două structuri de date foarte importante în Python: dicționarele și seturile.

Cu ajutorul lor poți organiza informații asemănător unei baze de date, unei liste de contacte sau unui catalog de produse.

1. Ce este un Dicționar?

Un dicționar este o colecție de perechi cheie – valoare.

Gândește-te la el ca la un tabel cu două coloane: într-o coloană avem cheia, iar în cealaltă avem valoarea asociată.

Exemplu:

print("=== Dicționarul meu de mașini ===")

masini = {
    "VW": "Polo",
    "BMW": "M5",
    "Kia": "Sportage"
}

print(masini)

În acest dicționar:

  • "VW" este cheia, iar "Polo" este valoarea;
  • "BMW" este cheia, iar "M5" este valoarea;
  • "Kia" este cheia, iar "Sportage" este valoarea.

2. Crearea unui Dicționar cu acolade

Cel mai simplu mod de a crea un dicționar este folosind acoladele { }. 

print("=== Crearea unui dicționar cu acolade ===")

john = {
    "name": "John Doe",
    "age": 25,
    "job": "Python Developer"
}

print(john)

Cheile și valorile sunt separate prin două puncte :, iar fiecare pereche este separată prin virgulă.

3. Accesarea unei valori

Pentru a lua o valoare dintr-un dicționar, folosim cheia dintre paranteze pătrate. 

print("Meseria lui John este:")
print(john["job"])

Python caută cheia "job" și întoarce valoarea asociată: "Python Developer".

Putem accesa și celelalte valori:

print("Nume:", john["name"])
print("Vârstă:", john["age"])

Este asemănător cu indexarea unei liste, dar în loc să folosim un număr, folosim o cheie.

4. Crearea unui Dicționar cu dict()

Un dicționar poate fi creat și folosind constructorul dict(). 

print("=== Crearea unui dicționar cu dict() ===")

jane = dict(
    name="Jane Doe",
    age=24,
    job="Web Developer"
)

print(jane)

În acest caz, cheile sunt scrise fără ghilimele în interiorul funcției dict().

Putem accesa vârsta lui Jane astfel:

print("Vârsta lui Jane este:")
print(jane["age"])

5. Ordinea elementelor

În versiunile moderne de Python, dicționarele păstrează ordinea în care elementele au fost introduse.

Acest comportament este garantat începând cu Python 3.7.

6. Metoda get()

O metodă mai sigură pentru accesarea valorilor este get(). 

print(john.get("job"))

Diferența este că, dacă cheia nu există, metoda get() nu oprește programul cu o eroare. 

print(john.get("city"))

În acest caz, Python va afișa None.

Putem oferi și o valoare implicită: 

print(john.get("city", "Oraș necunoscut"))

7. Chei, valori și perechi

Python oferă metode speciale pentru a vedea separat cheile, valorile sau toate perechile dintr-un dicționar.

keys()

Metoda keys() întoarce toate cheile. 

print(john.keys())

Rezultat asemănător:

dict_keys(['name', 'age', 'job'])

values()

Metoda values() întoarce toate valorile. 

print(john.values())

Rezultat asemănător:

dict_values(['John Doe', 25, 'Python Developer'])

items()

Metoda items() întoarce toate perechile cheie – valoare. 

print(john.items())

Rezultat asemănător:

dict_items([
    ('name', 'John Doe'),
    ('age', 25),
    ('job', 'Python Developer')
])

Aceste metode sunt foarte utile atunci când lucrăm cu bucle și vrem să parcurgem informațiile dintr-un dicționar.

8. Ce este un Set?

Un set este o colecție de valori unice.

Asta înseamnă că un set nu păstrează elementele duplicate.

De asemenea, seturile nu garantează o ordine fixă a elementelor. 

print("=== Ce este un set? ===")

nume = {
    "John",
    "Jane",
    "Linda"
}

print(nume)

Este important să reții că acoladele goale {} creează un dicționar gol, nu un set gol.

Pentru a crea un set gol, folosim: 

set_gol = set()

print(set_gol)
print(type(set_gol))

9. Crearea unui Set cu set()

Putem crea un set și folosind constructorul set(). 

print("=== Crearea unui set cu set() ===")

alte_nume = set([
    "David",
    "Mark",
    "Marie"
])

print(alte_nume)

Constructorul set() poate transforma o listă într-un set.

10. Eliminarea valorilor duplicate

Una dintre cele mai utile caracteristici ale seturilor este eliminarea automată a valorilor duplicate. 

print("=== Eliminarea valorilor duplicate ===")

numere = [1, 2, 2, 3, 4, 5, 3]

print("Lista originală:")
print(numere)

print("După transformarea în set:")
print(set(numere))

Valorile 2 și 3 apar de mai multe ori în listă, dar în set vor apărea o singură dată.

Dacă vrem să obținem din nou o listă fără duplicate, putem scrie: 

numere_unice = list(set(numere))

print(numere_unice)

11. Operații pe Seturi

Seturile permit operații asemănătoare celor din matematică. 

primes = {2, 3, 5, 7}
evens = {2, 4, 6, 8}

Uniunea

Uniunea combină toate elementele din cele două seturi, fără duplicate. 

print("Uniune:")
print(primes | evens)

Putem face același lucru și folosind metoda union(). 

print(primes.union(evens))

Intersecția

Intersecția păstrează doar elementele care apar în ambele seturi. 

print("Intersecție:")
print(primes & evens)

În acest exemplu, rezultatul este {2}, deoarece numărul 2 apare în ambele seturi.

Putem folosi și metoda: 

print(primes.intersection(evens))

Diferența

Diferența păstrează elementele care există în primul set, dar nu există în al doilea. 

print("Diferență:")
print(primes - evens)

Putem folosi și metoda: 

print(primes.difference(evens))

Atenție: ordinea contează. 

print(primes - evens)
print(evens - primes)

12. Adăugarea elementelor într-un Set

Pentru a adăuga un singur element într-un set, folosim metoda add(). 

primes = {2, 3, 5, 7}

print("Înainte:")
print(primes)

primes.add(11)

print("După adăugare:")
print(primes)

Dacă elementul există deja, Python nu îl va adăuga din nou. 

primes.add(5)

print(primes)

13. Eliminarea elementelor dintr-un Set

Pentru a elimina un element, putem folosi metoda remove(). 

primes.remove(11)

print(primes)

Dacă elementul nu există, metoda remove() produce o eroare.

O variantă mai sigură este metoda discard(). 

primes.discard(100)

print(primes)

Dacă valoarea 100 nu există, programul continuă fără eroare.

14. Seturile sunt modificabile

Seturile sunt mutabile, ceea ce înseamnă că putem adăuga și elimina elemente după ce setul a fost creat.

Totuși, elementele din interiorul unui set trebuie să fie valori care nu se modifică, precum numere, stringuri sau tuple.

Rezumat

În această lecție ai învățat:

  • ce este un dicționar;
  • cum creezi dicționare folosind {} și dict();
  • cum accesezi valorile unui dicționar;
  • cum folosești metoda get();
  • cum folosești keys(), values() și items();
  • ce este un set;
  • cum elimini valorile duplicate;
  • cum faci uniunea, intersecția și diferența dintre seturi;
  • cum adaugi și elimini elemente dintr-un set;
  • diferența dintre remove() și discard().

Încheiere

Acum știi să lucrezi cu dicționare și seturi, două dintre cele mai utile structuri de date din Python.

Dicționarele te ajută să organizezi informațiile folosind perechi cheie – valoare, iar seturile te ajută să păstrezi valori unice și să elimini duplicatele.

În lecția următoare vom învăța despre tupluri, liste avansate și mutabilitate, pentru a putea începe să construim programe mai complexe.

Condiții în Python

Astăzi învățăm condițiile din Python: if, elif și else. Astea sunt baza oricărei logici. Dacă înțelegi lecția asta, poți deja să construiești mini-aplicații reale

Durată: 03:14

Vezi scriptul lecției

Introducere

Astăzi vom învăța unul dintre cele mai importante concepte din programare: condițiile.

În Python folosim instrucțiunile if, elif și else pentru a lua decizii.

Aproape orice aplicație folosește condiții:

  • verificarea unui cont de utilizator;
  • verificarea vârstei;
  • calcularea reducerilor;
  • validarea datelor introduse;
  • reguli într-un joc;
  • afișarea notificărilor.

1. Ce este o condiție?

O condiție este o întrebare la care programul poate răspunde doar cu True sau False.

Dacă răspunsul este adevărat, Python execută un anumit bloc de cod. Dacă răspunsul este fals, poate executa alt bloc de cod.

Sintaxa este foarte simplă:

if conditie:
    # cod executat dacă rezultatul este True

Observă cele două puncte : și indentarea codului. În Python, indentarea este obligatorie.

2. Exemplu practic - Verificarea unui Login

Să presupunem că avem un sistem simplu de autentificare. 

user = "carla"
password = "1234"

if user == "carla" and password == "1234":
    print("Login reușit!")
else:
    print("Date greșite!")

Programul verifică dacă utilizatorul și parola sunt corecte.

Dacă ambele condiții sunt adevărate, utilizatorul se poate conecta. În caz contrar, este afișat un mesaj de eroare.

Exact acest principiu este folosit și de majoritatea site-urilor și aplicațiilor.

3. if, elif și else

Uneori avem mai multe posibilități, nu doar două.

În acest caz folosim elif, care înseamnă "altfel, dacă". 

age = 16

if age >= 18:
    print("Ești adult.")
elif age >= 13:
    print("Ești adolescent.")
else:
    print("Ești copil.")

Python verifică condițiile de sus în jos.

  • dacă prima condiție este adevărată, celelalte nu mai sunt verificate;
  • dacă prima este falsă, Python verifică instrucțiunea elif;
  • dacă nici aceasta nu este adevărată, execută blocul else.

4. Exemplu practic - Reducere într-un magazin online

Condițiile sunt folosite foarte des în magazinele online pentru a calcula reducerile. 

total = 320

if total > 500:
    print("Reducere 20%")
elif total > 300:
    print("Reducere 10%")
else:
    print("Nicio reducere")

În acest exemplu:

  • dacă valoarea coșului este mai mare de 500, clientul primește 20% reducere;
  • dacă este mai mare de 300, primește 10% reducere;
  • în rest, nu primește nicio reducere.

Același tip de logică este folosit de majoritatea magazinelor online.

5. Comparatorii în Python

Pentru ca Python să poată lua decizii, trebuie să comparăm valori.

Cei mai utilizați operatori de comparație sunt:

  • == → egal cu
  • != → diferit de
  • > → mai mare decât
  • < → mai mic decât
  • >= → mai mare sau egal
  • <= → mai mic sau egal

Exemplu:

age = 18

print(age == 18)
print(age != 18)
print(age > 18)
print(age >= 18)

Fiecare comparație va întoarce una dintre valorile True sau False.

6. Operatorii logici

Uneori trebuie să verificăm mai multe condiții în același timp.

Pentru asta folosim operatorii logici:

  • and → toate condițiile trebuie să fie adevărate;
  • or → este suficient ca una dintre condiții să fie adevărată;
  • not → inversează rezultatul unei condiții.

Operatorul and

age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Poți intra.")

Programul execută codul doar dacă ambele condiții sunt adevărate.

Operatorul or

is_admin = False
is_owner = True

if is_admin or is_owner:
    print("Acces permis.")

Este suficient ca una dintre condiții să fie adevărată.

Operatorul not

logged_in = False

if not logged_in:
    print("Te rugăm să te autentifici.")

Operatorul not inversează rezultatul unei condiții.

7. Exercițiul 1 - Verifică vârsta

age = int(input("Introdu vârsta: "))

if age >= 18:
    print("Adult")
else:
    print("Minor")

8. Exercițiul 2 - Număr par sau impar

Folosește operatorul modulo % pentru a verifica dacă un număr este par sau impar. 

number = int(input("Introdu un număr: "))

if number % 2 == 0:
    print("Număr par")
else:
    print("Număr impar")

9. Exercițiul 3 - Evaluarea unei note

Creează un program care afișează un mesaj în funcție de nota obținută. 

grade = int(input("Introdu nota: "))

if grade >= 9:
    print("Excelent!")
elif grade >= 7:
    print("Bine!")
else:
    print("Mai încearcă!")

Rezumat

În această lecție ai învățat:

  • cum funcționează instrucțiunea if;
  • cum folosești elif și else;
  • operatorii de comparație;
  • operatorii logici and, or și not;
  • cum să construiești programe care iau decizii;
  • cum să exersezi folosind exemple din viața reală.

Încheiere
